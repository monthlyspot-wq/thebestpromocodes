How referral links work

A referral (or invite) link is a signup link shared by an existing customer. A friend signs up through that referral, and rewards may go to one or both sides, depending on the operator. On this page, only the Caesars and BetMGM guides list a reward for both sides; FanDuel and DraftKings are welcome offers via our referral link.

  • No typed code. The offer attaches when you use the referral link; you do not enter a promo code string.
